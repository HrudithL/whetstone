# Support

- **Bugs and feature requests**: open a [GitHub issue](https://github.com/HrudithL/whetstone/issues/new/choose).
- **Questions about usage**: open a [GitHub Discussion](https://github.com/HrudithL/whetstone/discussions)
  if enabled, otherwise a GitHub issue is fine.
- **Security vulnerabilities**: see [SECURITY.md](SECURITY.md) — do not file a public issue.

## Tell us what isn't sticking

Whetstone's whole thesis is that a skill should learn from correction instead of repeating the same
mistake. The project should hold itself to the same standard: if a preference you taught Whetstone
isn't sticking, if `recall` is missing something obvious, or if the docs don't match what you're
seeing, please file an issue with the specific skill/scenario and what you expected — that feedback
is exactly what's currently missing from the project's own harness-only evidence, and it's the most
useful thing you can send.
