# Brief: Marrow — landing page hero

**Product:** Marrow, a command-line tool that turns a repo's test suite into a living map of what
each test actually covers.

**Audience:** staff+ engineers who own large, slow test suites.

**Primary purpose of the page:** get the visitor to run the one-line install.

## Hero section content

- **Eyebrow:** "Open source · MIT"
- **Headline:** "Know what your tests actually cover."
- **Subtext:** "Marrow watches a single test run and draws the real map from test to code — no
  coverage annotations, no config. Find the dead tests. Find the untested lines. In one command."
- **Primary CTA:** button labelled "Install Marrow"
- **Secondary CTA:** text link "Read the docs"
- **Trust line under the CTAs:** "Works with pytest, Jest, and go test."

Build just the hero section (above the fold). It should feel like a tool for people who live in a
terminal.
