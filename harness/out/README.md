# `out/` — generated artifacts (committed)

Everything under `out/` is **generated by the harness and committed to git** so the site renders
deterministically and CI needs no API key. The Quarto site in [`../../docs/`](../../docs/) only
*reads* this directory — it never regenerates it. Regenerate with the runner (slice 3):

```bash
pip install -e ".[showcase,embeddings]"    # from the repo root
python -m harness.run --agent               # command-only; drives a live model, never runs in CI
```

A mode is required — `--agent` (paid; writes these committed artifacts) or `--stub` (free
verification; writes to a throwaway dir and never touches `out/`).

## Layout (populated by slices 3–4)

```
out/
  metrics.json                         aggregate metrics for the dashboard (see ../schema.py)
  <scenario>/                          one dir per scenario (e.g. sp500_monthly_performance/)
    cold/
      table.py                         generated great-tables code, empty store (before)
      table.png                        rendered table
      transcript.json                  raw model transcript for the run
    warm/
      table.py                         generated code after the learned layer was applied (after)
      table.png
      transcript.json
    recall.json                        the verbatim recall() payload the warm run received
    diff.txt                           cold -> warm code diff
    runs.jsonl                         per-run records feeding runs-to-stick / value-over-time
```

Filenames are stable across re-runs so diffs stay reviewable.
